# Assets

Catalog reusable icons, illustrations, logos, imagery, and fonts here. Store
links, ownership, license, and usage guidance; keep binary assets in their
appropriate repository or asset-management location.

Create `assets/<slug>.md` from `templates/asset.md`; keep source and license
evidence with the usage contract. Lead owns durable records; Designer proposes
changes within the task handoff.

This catalog is durable. Absorption may update reusable asset records, but
transient cleanup never removes them. Keep retained provenance and usage links
independent of transient research or concept paths that will be removed.
