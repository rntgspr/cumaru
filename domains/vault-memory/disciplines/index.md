# Disciplines

Execution rules for *how* work is performed, distinct from the pillars that hold *what* the vault knows. Every installed discipline is delivered at context start; the trigger table in `domain.md` and each `applies-when:` determine which rules bind. `cumaru-first` is the priority application gate.
