# Roles

This domain has one role for daily work and framework maintenance.

## Available roles

- [admin.md](admin.md) — the sole role, with full local access within the user's requested scope.

## When to use

Load Admin by default at session start. No explicit role selection is required.

Do not split responsibilities into additional roles in this domain. The single
role may carry another name when the project prefers one; only its count is
fixed.
